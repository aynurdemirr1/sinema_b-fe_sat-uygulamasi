# sinema_büfe_satış uygulamasi
Sinema Büfe Satış Uygulaması 🎬🍿

Merhaba! Bu küçük ama eğlenceli proje ile C# Windows Form kullanarak bir sinema büfesi satış uygulaması geliştirdim. Hem kasa hesaplaması yapıyor, hem de kullanıcı dostu bir arayüz sunuyor!

Özellikler ✨

Mısır, su, çay ve bilet satış girişi

Anlık toplam tutar ve kasa güncelleme

Temizle butonu ile sıfırlama özelliği

Kolay kullanımlı arayüz


Kullanılan Teknolojiler 🛠️

C#

Windows Forms

Visual Studio
